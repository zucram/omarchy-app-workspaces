# App Workspaces

App Workspaces is an MIT fork of Decent Workspaces for the Omarchy bar.
Preserve upstream attribution in README.md, NOTICE.md, and LICENSE.

Read README.md before changing behavior. Run `node --test tests/*.cjs` for
model changes and verify QML in a running Omarchy 4 shell before release.
Record the observed results and untested configurations in docs/validation.md.

The workstation deployment and rollback belong to the sibling Omarchy project,
not this distributable plugin. Read its AGENTS.md and docs/workspace-icons.md
before deployment. Public releases and marketplace submissions require owner
approval of the concrete release and submission text.
